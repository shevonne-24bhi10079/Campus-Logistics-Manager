# Campus-Logistics-Manager
A robust Java-based management system designed to streamline campus event logistics, hospitality resource tracking, and volunteer task coordination. Developed as a Capstone BYOP to solve real-world coordination challenges during university festivals using OOP principles and data persistence.
# EventFlow: Campus Logistics & Resource Manager

##  Project Overview
EventFlow is a Java-based command-line application developed to solve the coordination challenges faced during large-scale university festivals like adVITya. 

##  Key Features
* Inventory Tracking: Categorize and monitor stocks of refreshments and guest mementos.
* Volunteer Roster: Assign specific logistical duties to team members.
* Data Persistence: Uses Java Serialization to save data to event_data.dat.
* Error Handling: Robust management of user inputs and file-system exceptions.

##  Technical Stack
* Language: Java (JDK 17+)
* Core Concepts: OOP, Collections (ArrayList), File I/O, Serialization.

##  Installation & Setup
1. Compile: javac *.java
2. Run: java LogisticsManager
